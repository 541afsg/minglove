# 拾光笔记

面向 Android 手机的生活记录 PWA。应用页面通过 GitHub Pages 提供；日记文字和照片保存在使用者自己的手机浏览器里，不会上传到 GitHub。

## 功能

- 记录心情、日常、灵感和重要时刻，可添加标题、标签、地点、天气和照片。
- 按月份查看日历，或在全部记录中搜索和筛选。
- 导出 JSON 备份，并从备份文件恢复。
- 首次在线打开后可安装到 Android 主屏幕，并支持离线打开已缓存的应用页面。

## 数据说明

文字保存在浏览器本地存储，压缩后的照片保存在本机 IndexedDB。GitHub Pages 只托管应用文件，不接收日记数据。清理浏览器数据、换设备或换浏览器时，记录不会自动同步；请在“我的”页面导出备份并自行保管。

## Android 安装

1. 在 Android 手机上用 Chrome 打开 GitHub Pages 地址。
2. 点页面上的“添加到手机桌面”，或打开 Chrome 菜单并选择“安装应用”。
3. 安装后从桌面图标打开；记录保存在这台手机的 Chrome 应用数据中。

## 本地预览

在 `dist` 目录启动静态 HTTP 服务即可预览。PWA 安装和离线缓存需要通过 HTTPS 访问，不能直接用 `file://` 打开。
