# 拾光笔记

面向 Android 手机的拾光笔记。应用页面通过 GitHub Pages 提供，也可安装独立 Android APK。日记、工作记录和生活数据保存在使用者自己的手机里，不会上传到 GitHub。

## 功能

- 底部一级导航分为工作、生活、回顾和我的。
- 工作页记录四档状态、卡点、下一步和收尾结论；点击“今天工作结束”后切换到生活页。
- 生活页可记录一天中的多项活动、运动时长与距离、心情、照片；活动建议按精力和偏好整理，周末保留自由选择。
- 我的页面可记生活待办、维护活动池，或添加未来倒数与已过天数（例如加入公司）。
- 回顾页保留原日记、月历和搜索，并将工作与生活按日期做简短周回顾。
- 导出完整 JSON 备份，并从备份文件恢复。
- 网站支持安装到 Android 主屏幕和离线打开；独立 Android APK 也可直接安装。

## 数据说明

文字、工作日志、活动和待办分别保存在浏览器本地存储，压缩后的照片保存在本机 IndexedDB。选择照片时仅读取用户选中的图片，不扫描整个相册。GitHub Pages 只托管应用文件，不接收记录数据。清理浏览器数据、换设备或换浏览器时，记录不会自动同步；请在“我的”页面导出备份并自行保管。

应用当前不连接生成式 AI 服务。工作提示、收尾文字、活动建议和周回顾由本机规则生成，数据不会发送到 AI 服务。

## Android 安装

1. 在 Android 手机上打开 GitHub Pages 地址，或下载 shiguangbiji.apk。
2. 网站版可通过 Chrome 菜单安装到主屏幕；APK 下载后按系统提示安装独立应用。
3. 网站版与 APK 版的数据空间互相独立；换到另一版前，请先导出完整备份再导入。

## 本地预览

在 `dist` 目录启动静态 HTTP 服务即可预览。PWA 安装和离线缓存需要通过 HTTPS 访问，不能直接用 `file://` 打开。
